ForgeAI

Drop-in OpenAI-compatible router that cuts inference cost by up to 72.9%

The Challenge: Fixed Routing

Traditional routers like LiteLLM and OpenRouter operate on Fixed Routing. When a user request comes in, they only pick a model. But model selection is only one lever of inference optimization.

ForgeAI solves this by treating inference routing as a Joint Optimization problem across model, precision, and retrieval.

System Overview

By simply pointing your OpenAI SDK to ForgeAI, the API Gateway intercepts the request and offloads it to a Contextual Bandit which makes a joint decision.

Key Capabilities

  • Drop-in OpenAI-compatible API: Change one line, same SDK, same response shape.
  • Contextual Bandit Policy: Uses LinUCB to select one of 81 joint actions based on 8 live features.
  • Massive Savings: Achieves up to 72.9% lower cost on real H100 benchmarks.
  • Offline Retraining: Decisions are logged asynchronously and policies are retrained on actual cost/latency outcomes.
