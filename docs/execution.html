Execution Engine

High-Performance Inference and Execution

Model Inference

The Execution Engine is responsible for the heavy lifting: running the actual LLM inference. It leverages vLLM to provide extremely high throughput and low latency, backed by CUDA and PyTorch.

Cost Tracking & Headers

Once execution is complete, the engine calculates the precise cost of the inference based on the model tier and precision used. This data is injected directly into the response headers, so developers have full visibility into cost optimization.

  • x-forgeai-model: The routed model tier.
  • x-forgeai-precision: The quantization level.
  • x-forgeai-cost: Micro-cent level cost tracking.
  • x-forgeai-latency: Total turnaround time.
