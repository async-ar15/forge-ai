Microservice Architecture

FastAPI, gRPC, and Asynchronous Operations

The gRPC Backbone

ForgeAI is composed of highly specialized, decoupled microservices. While the entrypoint is a FastAPI-based REST gateway for OpenAI compatibility, internal communication runs exclusively over low-latency gRPC and Protocol Buffers.

Service Breakdown

  • API Gateway (FastAPI): Implements the /v1/chat/completions endpoint. Normalizes features and orchestrates the request.
  • Registry Service: Powered by PostgreSQL and Alembic. Manages tenant-specific configuration, API keys, and model catalog.
  • Policy Service: The LinUCB brain. Receives state vectors and returns the optimal routing action.
  • Execution Service: Dispatches to actual LLM engines (like vLLM) based on the Policy Service's decision.
  • Retrieval Service: Manages RAG and semantic caching using Qdrant and Redis.
  • Training / Eval: Consumes the Kafka logs asynchronously to evaluate policy performance and train new offline checkpoints.
